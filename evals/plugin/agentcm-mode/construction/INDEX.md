# AgentCM agent index: Smoke project

Generated by AgentCM from its database, and regenerated when sheets change: do not edit.

- `sheets/<sheet>.txt`: the sheet's text as paragraphs in reading order (column by column), one per line: paragraph, x, y, text. Positions run from 0 to 1 from the top left of the sheet. A sheet with views has a heading per view (`## view J13: TOILET 1607, 1/4" = 1'-0" (x, y, w, h; ...)`) with its paragraphs under it; the area is drawn by a person or estimated from where the labels are.
- `sheets/<sheet>.tsv`: one line of text per row: x, y, w, h, source, tag, how, label, paragraph, view, zone, text. Tag is detection's; how says whether a person accepted it in Group Review (accepted) or not yet (pending); label is a person's own; zone is the cell of the sheet's border grid (`J13`). Search the text, then read where it is.
- `schedules/<sheet>-<n>.tsv`: one file per schedule, legend or keyed-notes table on a sheet, listed below under Schedules and legends: a comment line, a header line, then one line per row, cells by column. From the sheet's text: the row's position y, then its cells, the table's own header rows first; from a schedule ingested into AgentCM: its rows under the drawing's column headers. The comment line ends with `schedule_id=` and the ingested schedule's id, `none` for a table read from the text. Read a room's finishes or a door's size here.
- `sheets/<sheet>.rows.txt`: the text on each line across the sheet, cells left to right between tabs, outside the sheet's tables: a table the files above do not have, or a table's rows they miss (at the sheet's edge). Each row is in exactly one of `schedules/` and `.rows.txt`, so search both.
- `sheets/<sheet>.groups.tsv`: callouts and tags accepted in AgentCM's Group Review: type, box, link (sheet:detail), text.
- `specs/<section>.txt`: a specification section's text, each line starting with its page in the manual (`pg440`); the headers and footers every page repeats are left out.
- `tags.tsv`: every occurrence of a known identifier (a room, a door, a tag, a grid line), one per line: id, kind, sheet, x, y, view, how, text, sorted by id. How: accepted, schedule or text. One room across the set: the lines starting with `1607\t`.
- `crop.sh` and `crop.ps1`: `sh .construction/crop.sh <sheet> <x> <y> <w> <h>` renders that box of the sheet's PDF page as a PNG in `crops/` and prints its path; the box is in the sheet files' positions.
- `pending.tsv`, only while AgentCM is behind: the sheets whose files wait for a refresh (queued) or whose last refresh failed (failed, with the reason): sheet, since, state, reason. No file means every sheet's files are current.
- `xrefs.tsv`: every reference between sheets, details and specification sections, one per line: from, x, y, view, kind, to, detail, target, how, found, text. Kind: callout or multi_callout (accepted in Group Review), mention (found in the text), list (on a drawing list), title (a view's own mark, its id over its own sheet's number: where that view is). Target: sheet, spec, discipline (another discipline named, "SEE STRUCTURAL"), missing (not in this project). How: accepted or text. Found: the detail is on the target sheet as a view label (yes, no), or removed (an earlier version of the target sheet showed it and the current one does not: a revision took it away). What refers to A-101: lines with `\tA-101\t`.
- Text `partial`: part of the page needed OCR that was not run, so a search that finds nothing there proves nothing. `pending` and `failed` pages have no text yet.
