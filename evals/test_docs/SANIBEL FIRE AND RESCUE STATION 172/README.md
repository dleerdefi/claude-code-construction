# Sanibel Fire and Rescue Station 172

Test project for the construction skills evals. Per the project summary on the drawings, the project is a new two-story fire station facility, built after demolition of an existing building.

The facts below are from the project manual cover and title pages.

| | |
|---|---|
| **Documents** | 100% Construction Documents, issued January 5, 2024 |
| **Commission No.** | 2023820 |
| **Owner** | Sanibel Fire and Rescue District |
| **Architect** | Schenkel Shultz Architecture |
| **Structural** | TRC Worldwide Engineering, Inc. |
| **Mechanical / Electrical / Plumbing / Fire Protection / Technology** | OCI Associates, Inc. |
| **Civil** | RESPEC |

## Folder Structure

```
01 - Drawings/          ← drawing PDFs (downloaded separately)
02 - Specifications/    ← project manual, two volumes (downloaded separately)
05 - RFIs/              ← blank RFI log
08 - Daily Reports/     ← blank daily report template
14 - Punch List/        ← blank punch list template
15 - Closeout/          ← empty
16 - Templates/         ← blank forms: bid form, bid tab, procurement log, daily report,
                          punch list, rough-in inspection checklist, safety plan
```

## Getting the Drawings and Specifications

The PDFs are too large for the repository. Download them with the links in [`docs/RUNNING_EVALS.md`](../../../docs/RUNNING_EVALS.md#get-test-documents) and place them in `01 - Drawings/` and `02 - Specifications/`. Git ignores everything inside those two folders.

The drawing set contains the architectural, civil, electrical and mechanical sheets. The cover sheet also indexes structural, plumbing, fire protection, technology and landscape sheets, which are not part of this set.
